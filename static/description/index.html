Advanced Grid

The Microsoft Dynamics 365 Color Grid experience, inside Odoo 19.

Odoo 19 · Community & Enterprise

Personalise any list, without touching the view

Row & cell colouring

Paint a whole row or a single column based on a field value or a full domain. Background, text colour, bold and italic.

Status icons

Add a FontAwesome icon at the start of the row — hot deals, blocked records, overdue items — with its own colour.

Personal by default

Every user builds their own scheme. Nobody else sees it. Managers can publish shared schemes for the whole company.

Nothing breaks

No view arch is modified, no core method is replaced. Native decoration-*, optional columns and editable lists keep working.

گرید پیشرفته برای اودو ۱۹

تجربه‌ی Color Grid مایکروسافت داینامیکس ۳۶۵ را به هر نمای لیستی در اودو می‌آورد. هر کاربر می‌تواند لیست‌های خودش را رنگ‌آمیزی و آیکن‌گذاری کند، بدون اینکه نمای دیگران تغییری کند و بدون اینکه ساختار view دست بخورد.

رنگ‌بندی سطر و سلول

کل سطر یا فقط یک ستون را بر اساس مقدار یک فیلد یا یک دامنه‌ی کامل رنگ کنید؛ رنگ پس‌زمینه، رنگ متن، درشت و کج.

آیکن وضعیت

ابتدای هر سطر یک آیکن با رنگ دلخواه اضافه کنید تا رکوردهای مهم فوراً دیده شوند.

شخصی و اشتراکی

قواعد شخصی فقط برای خود کاربر اعمال می‌شود؛ مدیر می‌تواند طرح رنگی در سطح شرکت منتشر کند.

بدون آسیب به عملکرد اودو

هیچ view ای تغییر نمی‌کند و هیچ متد اصلی جایگزین نمی‌شود؛ فقط افزونه‌ی غیرمخرب روی رندرر لیست.
